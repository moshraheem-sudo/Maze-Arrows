## ✨ المميزات الرئيسية للتطبيق (Key Features)

### 1. 🎮 أسلوب لعب ذكي ومتدرج (500 مرحلة)
- **500 مرحلة متدرجة:** موزعة على 5 مستويات صعوبة (`سهل`، `متوسط`، `صعب`، `خبير`، `احترافي`) مع تنويع ذكي تلقائي بين الأوضاع للحفاظ على متعة اللعب.
- **خوارزمية التوليد العكسي الذكي (Smart Reverse-Move Generator):** توليد لوحات متقاربة وممتلئة بالكامل فوق شبكة نقاط واضحة (`Dot Grid`) مع التحقق الآلي عبر `Solver` من قابلية الحل بنسبة 100%.
- **تحديد المستوى الحالي بدقة:** عرض مستوى اللاعب الحالي بوضوح في الواجهة الرئيسية (`المستوى 1 (المستوى الأول)`، `المستوى 2 (المستوى الثاني)`، إلخ).

### 2. 🔍 فحص المسار والتقريب السلس (Path Preview & Smooth Zoom)
- **معاينة المسار بالضغط المطوّل:** عند الضغط المستمر على أي سهم، يظهر مساره الفعلي بخط مستقيم منقط وشفاف لمدة 3 ثوانٍ لمعرفة اتجاه خروجه وما إذا كان يتقاطع مع أسهم أخرى، ثم يختفي تلقائياً.
- **تحكم سلس بالتقريب والتبعيد (Pinch-to-Zoom & Pan):** تقريب وتبعيد وتمرير اللوحة بإصبعين بسلاسة تامة دون تفعيل الأسهم عن طريق الخطأ، مع اقتصاص حدود اللوحة (`Clip`) بحيث لا تتداخل الأسهم الصاعدة مع البطاقات العلوية أو السفلية.

### 3. ⏱️ نظام المحاولات الخمس والمؤقت الفعلي والفرص الإضافية
- **5 محاولات لكل مرحلة + مؤقت فعلي:** تبدأ كل مرحلة بـ **5 محاولات** ومؤقت تنازلي فعلي.
- **نافذة التخيير عند انتهاء المحاولات أو الوقت:** عند نفاد المحاولات الخمس، يظهر خيار فوري للاعب بين:
  1. **شراء 5 محاولات إضافية والمتابعة فوراً** في نفس اللوحة دون خسارة التقدم.
  2. **شراء البقاء في نفس المستوى والوضع دون تغيير الصعوبة** وإعادة فتح المرحلة بنفس وضعها الحالي.
  3. **فتح نفس المستوى بوضع أصعب مجاناً** مع 5 محاولات جديدة.

### 4. 🛒 متجر النقاط التفاعلي ونظام المساعدات (Points Shop & Cooldowns)
- **قفل زمني منظم (3 دقائق):** أدوات المساعدة (`تلميح`، `فحص المسار`، `حل تلقائي`) تعمل وفق مؤقت تهدئة لمدة **3 دقائق** بعد كل استخدام.
- **الحل التلقائي التعليمي:** يعرض طريقة حل المرحلة خطوة بخطوة للتعلّم، ولكن **لا يمكن تجاوز المرحلة أو فتح المرحلة التالية إلا عندما يحلّها اللاعب بنفسه**.
- **شراء المزايا بالنقاط المكتسبة:**
  - فتح التلميح وفحص المسار والحل التلقائي فوراً دون انتظار الـ 3 دقائق.
  - شراء وقت إضافي (`+60 ثانية`) للمؤقت الفعلي.
  - تثبيت اللعب في وضع صعوبة معين دون تصاعد إجباري.

### 5. 🎨 مبدل الثيمات الكامل وواجهة الإعدادات بملء الشاشة
- **مبدل الثيمات (Theme Mode):** دعم كامل وعالي التباين لـ:
  - ☀️ **الثيم الفاتح (Light Mode)**
  - 🌙 **الثيم الداكن (Dark Mode)**
  - 📱 **الثيم الافتراضي للنظام (System Default)**
- **شاشة إعدادات كاملة النافذة (Full-Screen Settings):** مقسمة ومنصفة في منتصف الشاشة مع احترام أزرار وشريط التنقل في الهاتف وعدم التداخل معها.
- **مؤثرات بصرية واهتزاز تفاعلي:** احتفالية نجوم متحركة واهتزاز خفيف عند إكمال المراحل بنجاح.

### 6. ☁️ التحديث والتنزيل المباشر بالميجابايت (MB) داخل التطبيق عبر GitHub
- فحص ومقارنة الإصدار الحالي المثبّت (`v1.0`) مع أحدث إصدار منشور على مستودع GitHub الرسمي.
- **تنزيل التحديث بالميجابايت (`MB`) داخل التطبيق بالكامل** مع شريط تقدم حي (`تم تنزيل X.X MB من Y.Y MB • %`) وتشغيل مثبت النظام الرسمي (`FileProvider`) بأمان تام وبدون الحاجة لفتح متصفح خارجي.

## 📦 طريقة النشر والتحديث على GitHub (How to Publish Releases on GitHub)

لكي يعمل زر التحديث التلقائي داخل التطبيق عند إصدار نسخة جديدة مستقبلاً:
1. ارفع ملفات المشروع وملف **`MazeArrows.apk`** إلى المستودع:
   `https://github.com/moshraheem-sudo/Maze-Arrows`
2. من صفحة المستودع على GitHub، ادخل إلى قسم **Releases** ثم اضغط **Create a new release**.
3. اكتب رقم الإصدار في خانة **Tag version** (مثل `v1.0` حالياً، أو `v1.1` عند نشر تحديث جديد).
4. أرفق ملف **`MazeArrows.apk`** ضمن خانة **Attach binaries (Assets)** ثم اضغط **Publish release**.
5. سيتعرف التطبيق تلقائياً على الإصدار الجديد ويقوم بتنزيله بالميجابايت وتثبيته مباشرة من داخل شاشة الإعدادات.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **اللغة:** Kotlin 2.0+
- **واجهة المستخدم:** Jetpack Compose + Material Design 3
- **قاعدة البيانات المحلية:** Room Database (لحفظ تقدم المراحل، النقاط، النجوم، والإعدادات)
- **الأمان والتوافق:** متوافق 100% مع سياسات Google Play Protect (بدون صلاحيات خطرة، ويستخدم `FileProvider` الرسمي للتحديثات)
