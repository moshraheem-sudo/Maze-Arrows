## 🛡️ درع الأمان والخصوصية الحديدي (Zero-Data Protection Shield)

تم بناء التطبيق وفق مبدأ الأمان الصارم والخصوصية المطلقة لحماية هواتف المستخدمين:
1. **انعدام تام للصلاحيات الحساسة (Zero Sensitive Permissions):** لا وصول إطلاقاً للصور، الفيديوهات، الملفات الشخصية، جهات الاتصال، الموقع الجغرافي (GPS)، الميكروفون، الكاميرا، أو شريحة الهاتف (IMEI).
2. **معالجة محلية 100% (100% On-Device Processing):** جميع خوارزميات الذكاء والتوليد وحل الألغاز تجري محلياً على معالج الهاتف بدون استدعاء أي خوادم سحابية.
3. **انعدام أدوات التتبع والإعلانات (Zero Trackers):** خالٍ تماماً من Google Analytics أو Facebook SDK أو أي أدوات لجمع البيانات التسويقية.
4. **حظر الاتصالات غير المشفرة (Cleartext HTTP Blocked):** حظر بروتوكولات HTTP غير المشفرة وحصر الاتصال المشفر بـ TLS/HTTPS لفحص تحديثات GitHub فقط.
5. **عزل بيئة التخزين ومنع النسخ عبر USB (Sandbox & Anti-ADB Dump):** حفظ التقدم محلياً في الرام والذاكرة المعزولة المشفرة وتعطيل النسخ عبر `allowBackup=false`.
6. **حماية التراكب واللمس والشاشة (Anti-Tapjacking & FLAG_SECURE):** حماية لمسات المستخدم من النوافذ العائمة الخبيثة وخيار حظر التقاط الشاشة والتسجيل الخفي.
7. **مركز تدقيق الأمان المباشر (In-App Security Audit):** فحص فوري شامل داخل التطبيق للتحقق من سلامة كافة التدابير الأمنية.

## ✨ المميزات الرئيسية للتطبيق (Key Features)

### 1. 🎮 أسلوب لعب ذكي ومتدرج (500 مرحلة)
- **500 مرحلة متدرجة:** موزعة على 5 مستويات صعوبة (`سهل`، `متوسط`، `صعب`، `خبير`، `احترافي`) مع تنويع ذكي تلقائي للحفاظ على الإثارة.
- **خوارزمية التوليد العكسي الذكي (Smart Reverse-Move Generator):** توليد لوحات متقاربة وممتلئة بالكامل فوق شبكة نقاط واضحة (`Dot Grid`) مع التحقق الآلي عبر `Solver` من قابلية الحل بنسبة 100%.
- **تحديد المستوى الحالي بدقة:** عرض مستوى اللاعب الحالي بوضوح في الواجهة الرئيسية.

### 2. 🔍 شعاع المسار الأحمر الليزري فائق الوضوح (Laser Red Path & Smart Hint)
- **معاينة المسار والتلميح باللون الأحمر فائق الوضوح (0xFFFF1744):** عند الضغط المطوّل على أي سهم أو النقر على زر «تلميح»، يظهر فوراً شعاع أحمر قرمزي ناصع متوهج متعدد الطبقات (هالة ضوئية + إطار تباين + سهام توجيهية متحركة) يحدد بوضوح تام ودقة مجهرية مسار خروج السهم أو نقطة الاصطدام.
- **مؤشرات تفاعلية للهدف:** نقطة تصويب دائرية خضراء متوهجة عند خروج السهم بسلام، أو علامة تصادم متقاطعة حمراء واضحة عند وجود سهم يعترضه.
- **مدة عرض واضحة ومريحة:** يستمر الشعاع لمدة 7 ثوانٍ مع بطاقة إرشادية علوية باللغة العربية تبين حالة المسار («المسار سالك للخروج» أو «المسار مسدود بسهم آخر»).
- **تحكم سلس بالتقريب والتبعيد (Pinch-to-Zoom & Pan):** تكبير وتصغير وتمرير اللوحة بإصبعين بسلاسة مع اقتصاص حدود اللوحة.

### 3. ⏱️ نظام المحاولات الخمس والمؤقت الفعلي والفرص الإضافية
- **5 محاولات لكل مرحلة + مؤقت فعلي:** تبدأ كل مرحلة بـ **5 محاولات** ومؤقت تنازلي.
- **نافذة التخيير عند انتهاء المحاولات أو الوقت:**
  1. **شراء 5 محاولات إضافية والمتابعة فوراً** بالنقاط.
  2. **شراء البقاء في نفس المستوى والوضع** دون تغيير الصعوبة.
  3. **فتح نفس المستوى بوضع أصعب مجاناً** مع 5 محاولات جديدة.

### 4. 🛒 متجر النقاط التفاعلي ونظام المساعدات (Points Shop)
- **قفل زمني منظم (3 دقائق):** أدوات المساعدة تعمل وفق مؤقت تهدئة لمدة **3 دقائق**.
- **الحل التلقائي التعليمي:** يعرض طريقة الحل خطوة بخطوة للتعلّم، ولا يمكن تجاوز المرحلة إلا عندما يحلّها اللاعب بنفسه.
- **شراء المزايا بالنقاط:** فتح المساعدات فوراً، إضافة +60 ثانية، وتثبيت الأوضاع.

### 5. 🎨 مبدل الثيمات وشاشة الإعدادات الكاملة
- **دعم الثيم الفاتح، الداكن، والافتراضي للنظام** مع تباين نصوص عالي ووضع حماية البصر (قاعدة 20-20-20).
- **شاشة إعدادات كاملة النافذة** تحترم شريط التنقل للموبايل.

### 6. ☁️ التحديث والتنزيل المباشر بالميجابايت (MB) داخل التطبيق عبر GitHub

## 📦 طريقة النشر والتحديث على GitHub (How to Publish Releases on GitHub)

1. ارفع ملفات المشروع وملف **`MazeArrows.apk`** إلى المستودع:
   `https://github.com/moshraheem-sudo/Maze-Arrows`
2. ادخل إلى قسم **Releases** ثم اضغط **Create a new release**.
3. اكتب رقم الإصدار في خانة **Tag version** (`v1.70.0`).
4. أرفق ملف **`MazeArrows.apk`** ضمن خانة **Attach binaries (Assets)** ثم اضغط **Publish release**.
5. سيتعرف التطبيق تلقائياً على الإصدار الجديد ويقوم بتنزيله بالميجابايت وتثبيته مباشرة من داخل شاشة الإعدادات.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **اللغة:** Kotlin 2.0+
- **واجهة المستخدم:** Jetpack Compose + Material Design 3
- **قاعدة البيانات المحلية:** Room Database (معزولة ومشفرة محلياً)
- **الأمان والخصوصية:** درع أمان محصن (Zero-Data Extraction Shield)، حظر كامل للصلاحيات الحساسة، حظر Cleartext HTTP، وحماية من التراكب وهجمات اللمس.
